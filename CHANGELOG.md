# Changelog

All notable changes to this project will be documented here. Package release
notes are managed with [Changesets](https://github.com/changesets/changesets).

## 0.1.0 — Unreleased

Initial standalone release.

- Framework-agnostic TypeScript controller with approved default and subtle
  presets.
- Overscanned WebGL2 edge rendering with progressive blur, refraction, and RGB
  dispersion.
- Scroll velocity, peak hold, decay, and opposite-edge response.
- Inert DOM capture with exclusions, capture budgets, font refresh, and safe
  fallback.
- Explicit opt-in live-video compositing without changing source playback.
- CSS/backdrop-filter and reduced-motion behavior.
- React 19 component and hook with SSR and Strict Mode-safe cleanup.
- Original editorial demo, clean Vite examples, and browser regression suite.
